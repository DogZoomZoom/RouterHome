Welcome to Home Hub

Home Hub puts the pages you use to run your home network in one window, and watches your GL.iNet routers from the system tray. Choose what you want as tabs. You can change this any time.

Where is each one?

Enter the address you'd type in a browser. For a router, just its IP address. Use Check to make sure Home Hub can reach it.

Last few things

Next, Home Hub opens your tabs. Each one asks you to sign in the first time: routers on Home Hub's own sign-in page (the password is kept in Windows Credential Manager), everything else on its usual login page.
