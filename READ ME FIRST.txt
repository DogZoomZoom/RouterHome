ROUTER HOME - Home tab for GL.iNet routers
==========================================
(What every feature does: see FEATURE GUIDE.txt. What's new in each version: see CHANGELOG.txt)

Adds a "Home" dashboard as the first tab of your GL.iNet router's admin page. It shows the
system, internet, Wi-Fi, clients, network health and security status, plus a speed test,
alerts and more.

Tested on: Flint 3 (GL-BE9300), Brume 3 (GL-MT5000) and Slate 7 Pro (GL-BE10000), all on
GL.iNet firmware 4.x. The installer detects the model by itself: a Brume 3 gets the Brume 3
build, and every other model gets the general build. You don't have to pick anything. Other GL.iNet 4.x routers will probably work. The installer stops
safely if the router isn't running GL.iNet 4.x firmware.

WHAT YOU NEED
  - A Windows 10 or 11 PC or a Mac connected to the router (Wi-Fi or cable).
  - The router's IP address: the one you type to open its admin page (often 192.168.8.1).
  - The router's admin password.
  - SSH turned on in the router (the installer uses it). Check BEFORE you start:
    router admin page > Security > Access Control (or Admin Panel) > "Enable SSH" on > Apply.
    If it won't stay on, set a stronger admin password first: GL turns SSH off when the
    admin password is weak. If SSH is off, the installer says it can't reach the router.

HOW TO INSTALL ON A MAC
  1. Double-click the zip to extract it.
  2. Open Terminal (Applications > Utilities > Terminal).
  3. Type  sh  followed by a space, drag "Install Router Home (Mac).command" into the Terminal
     window, and press Return.
  4. Follow the same steps as below (choose 1, router IP, questions, password once).
  5. Reload the router's admin page with Cmd+Shift+R.
  (Double-clicking the .command file won't work straight from the zip, because macOS blocks
  downloaded scripts. The "sh + drag" method above avoids that.)

HOW TO INSTALL ON WINDOWS
  1. Extract this whole folder (don't run it from inside the zip).
  2. Double-click "Install Router Home.cmd".
  3. Choose 1, enter the router IP, and answer the speed-test question.
  4. Type the admin password when asked (just once). Nothing shows while you type.
  5. Open the router's admin page and press Ctrl+F5. "Home" is now at the top of the menu.

WHAT IT CHANGES
  - It adds the Home tab files and a small background service that collects the statistics.
  - It does NOT change Wi-Fi, firewall, VPN, DNS or passwords, and it doesn't turn any
    services off. (Once installed, the Home tab's Auto-heal can restart a stuck VPN
    tunnel, Wi-Fi band or service by itself; see FEATURE GUIDE section 4. Each repair
    can be switched off.)
  - Before replacing anything, it backs it up to /root/machome-backup/ on the router.
  - It survives firmware upgrades when "Keep settings" is selected.
  - Your password is typed straight into Windows' own SSH program. The installer never sees
    or saves it. Nothing is sent anywhere except to your router.
  - Only if you say yes, the router downloads Ookla's Speedtest CLI directly from Ookla.

OPTIONAL SECURITY / CLEANUP (asked one at a time, all off unless you say yes)
  After the speed-test question, the installer asks whether to skip these. If you don't skip,
  it explains each one and asks y/n:
    - Admin page HTTPS-only
    - Lock the VPN key file
    - Close the unused IPsec firewall ports
    - Harden a few kernel security settings
    - Check signatures on add-on packages
    - Remove an unused FTP entry
    - Turn off app detection (DPI)
    - Turn off cellular/SMS
    - Turn off Bonjour/mDNS (avahi)
    - Turn off the Bark client
    - Brume 3 only: VPN speed tuning (spreads packet handling over 3 CPU cores)
  Anything that isn't on your router is skipped. Every change is recorded, and you can undo
  all of them by running the installer again and choosing 3.
  "SSH key-only login" is deliberately NOT offered, because it would stop this installer from
  working again.

OPTIONAL SETUP (inside the Home tab)
  - Weather: enter your ZIP when the Home tab asks.
  - Discord alerts: Control Center > Settings > Discord alerts (paste your own Discord
    webhook there).
  - NAS backup: Control Center > Settings > NAS backup.
  - Auto-heal (problems the router fixes by itself): Control Center > Settings > Auto-heal.
    Most repairs are on already; the opt-in ones (including restarting a cable modem)
    stay off until you turn them on.

TO REMOVE IT
  Run "Install Router Home.cmd" again and choose 2. Your other router settings aren't touched.

TROUBLESHOOTING
  - "Can't reach SSH": check that the PC is connected to that router and that the IP is right.
    SSH is on by default on GL.iNet routers.
  - "REMOTE HOST IDENTIFICATION HAS CHANGED": the installer offers to fix this. It happens
    when the PC has connected to a different device at that IP before.
  - Home tab not showing: press Ctrl+F5 on the admin page.
